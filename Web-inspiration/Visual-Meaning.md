# Visual Meaning - reference (til looplo web)

Gemt 2026-09-26 som reference ifm. arbejdet med looplo web.

Firma: Visual Meaning (UK). Laver visuelle, data-drevne "maps", der samler
systemtaenkning, visuelt sprog og ontologi/data for at skabe delt forstaaelse
("shared meaning") i transformation. Relevant for koblingslag-visualisering og
det semantiske lag/ontologi.

navigerbare visuelle kort er en model for at vise koblingslaget.
